# Image Asset Intake

This folder holds the first open-license/public-domain image batch for the H5 demo.

## Usage Rules

- Keep attribution visible in the product or documentation when using CC BY / CC BY-SA files.
- Public domain and CC0 files are preferred for later commercial use, but still keep source credit for auditability.
- Bite, rash, eschar, or dermatitis images are examples only. They must not be presented as diagnosis.
- Species, local relevance, and medical wording still need expert review before production release.
- If an image is replaced, update both this file and `imageManifest` in `app.js`.
