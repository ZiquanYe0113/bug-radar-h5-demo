# Image Asset Intake

This folder holds image assets for the H5 demo.

Recommended structure:

- `bugs/`: insect body photos or illustrations used for visual identification.
- `bites/`: bite, sting, attachment, or skin reaction examples. These must always carry a non-diagnostic warning.
- `habitats/`: environment photos, such as lake shore, grass, drain, kitchen, or damp shaded areas.

Before replacing placeholders with real images, record:

- Source or photographer
- License or authorization status
- Whether it is a real photo, illustration, or generated image
- Expert verification status
- Whether medical/privacy review is needed

Bite reaction photos should avoid identifiable body parts and must not imply diagnosis.
