# 虫情雷达 H5 Demo

杭州春夏首发版防虫生活助手 Demo。当前版本用于展示 MVP 产品路径，不是医学诊断工具，也不是正式虫害预警系统。

## 如何打开

直接双击 `index.html` 即可本地打开。

也可以在项目目录启动本地服务：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://localhost:4173/index.html
```

如果要发给别人，把这些文件和目录一起打包：

- `index.html`
- `config.js`
- `styles.css`
- `app.js`
- `assets/`

## 核心页面

- 首页：今日附近虫情风险、重点虫类、重点出行场景。
- 我要出门：按杭州真实微环境选择场景，输出虫类风险、装备、现场判断和被咬第一步。
- 被咬了：按地点和表现给出候选虫类，不做医学诊断。
- 看到虫：按形态和环境给出识别候选。
- 虫类详情：展示场景、特征、防护、处理、核验状态和图片证据位。
- 家庭防虫：蚊子、蟑螂、蛾蚋、果蝇、跳蚤的家庭治理清单。
- 用户上报：分为被咬了、看到虫、家里有虫三类，上报会以低权重反馈到首页和出门页。
- 上报审核后台：查看上报统计、虫类分布、热点地点，并导出 CSV 做人工复核。
- 图片上报流程：虫体照片、叮咬反应照片和环境照片分开处理；Demo 只保存照片元信息。

## 第一阶段联网 MVP

当前版本已经预留 3 个真实服务接口：

- 天气风险：默认使用 Open-Meteo 获取杭州实时温度、湿度、降雨和风速。
- 地图定位：`config.js` 填入高德 Web JS API Key 后，首页会加载真实地图。
- 上报数据库：`config.js` 填入 Supabase URL 和 anon key 后，用户上报会先本地保存，再同步到 `bug_reports` 表。
- 运营后台：访问 `#/admin` 可以查看本地/云端上报汇总，并导出 CSV。

配置文件是 `config.js`。现在里面是空 Key，可直接展示 Demo；正式接入时只填浏览器端允许公开的 Key，不要放服务端密钥。

Supabase 建表 SQL 放在：

```text
SUPABASE_SCHEMA.sql
```

在 Supabase SQL Editor 里执行后，再把 `url`、`anonKey` 填到 `config.js`。

## 数据与规则

规则来自 `虫情雷达_MVP产品定义文档_v1.docx` 和 `杭州春夏虫害知识库_v1.json` 的首发版内容，并按杭州常见微环境做了 Demo 化整理。

当前重点场景包括：

- 西湖景区山脚短停
- 西湖湖岸/运河散步遇虫团
- 小区绿化带傍晚遛弯
- 西溪湿地/湘湖/公园停留
- 余杭/临安/富阳山地徒步
- 萧山/钱塘村镇河渠傍晚
- 钱塘江边夜跑/露营
- 宠物去草地后人腿脚成串红疹

## 图片素材

图片系统已经接入 `imageManifest`，当前使用本地 SVG 占位图：

- `assets/images/bugs/placeholder-bug.svg`
- `assets/images/bites/placeholder-bite.svg`
- `assets/images/habitats/placeholder-habitat.svg`

替换真实图片时，需要记录来源、授权、素材类型、专家核验状态和隐私/医学风险。叮咬反应图只用于风险提示，不能替代医生诊断。

用户上传照片当前采用隐私友好 Demo 流程：浏览器内可以预览，但提交时只记录照片分类、文件名、大小和 MIME 类型，不把图片原图写入 localStorage。后续接真实存储时，虫体照片可进入 AI 识别队列，叮咬反应照片默认进入人工/医学风险提示队列。

## 合规边界

- 不对皮肤照片或红斑做医学诊断。
- 涉及用药、感染、过敏、蜱虫处理等内容需要医生、疾控或专业资料核验。
- 用户位置、照片和健康描述应最小化采集。
- 商业化服务入口应和科普建议分离。
